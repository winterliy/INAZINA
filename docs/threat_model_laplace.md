# LAPLACE 내부 위협모델

2026-11-21 기준. 내부 금융 시뮬레이터의 자산, 행위자, 신뢰 경계, 위협, 통제, 잔여 위험을 코드와 시험에 근거해 적는다. 증빙이 없으면 **미비**로 쓴다. 실제 규제 인증이나 외부 감사 결과가 아니다. 통제 번호는 `docs/controls_laplace.md`의 행이다.

## 자산
| 자산 | 위치 | 중요도 이유 |
|---|---|---|
| 원장(지갑·계좌·분개) | PostgreSQL `inazina` | 사용자 잔액과 회계 정합성의 근거 |
| 관리자 권한 | 웹 API 역할 `admin`, `BOOTSTRAP_ADMIN_IDS` | 쓰기 경로 전체를 연다 |
| 내부 토큰 | 환경변수 `INAZINA_INTERNAL_TOKEN` | 대시보드·API와 파이썬 서버 사이의 인증 |
| 비밀번호 해시 | `web_auth_credentials` | 로그인 |
| 감사 기록 | `admin_audit` | 관리자 행위의 사후 추적 |
| 백업 덤프 | pg_dump 파일 | 복구 수단이자 민감 데이터 사본 |

## 행위자와 신뢰 경계
| 행위자 | 신뢰 | 경계 |
|---|---|---|
| 일반 사용자 | 낮음 | 웹 API의 사용자 경로. 본인 자원만 |
| 국가·기업 계정 | 낮음~중간 | 역할 확인 후 자기 범위만 |
| 관리자 | 높음(내부자) | `/internal/admin/*`. 역할 확인과 감사 |
| 운영자(서버 접근) | 최고 | DB 직접 접근. 코드 통제 밖 |
| 외부 네트워크 | 없음 | 내부 토큰 없이는 `/internal/*`가 401 |

## 위협, 통제, 잔여 위험
| ID | 위협 | 통제 | 증빙 | 잔여 위험 |
|---|---|---|---|---|
| T-01 | 일반 사용자가 관리자 경로를 호출한다 | 모든 `/internal/admin/*` 분기가 관리자 역할을 확인한다(GET 33, POST 28). 새 경로가 확인 없이 추가되면 정적 검사가 실패한다 | C-30, tests/test_m8_admin_route_authorization.py | 역할 값 자체가 틀리면 막지 못한다. 관리자 목록은 1명(2026-11-21 접근 검토) |
| T-02 | 관리자가 흔적 없이 데이터를 바꾼다 | 관리자 쓰기는 감사 행·감사 범위·관리자 명령 계층을 거친다. 민감 조회(사용자 목록, 조달, ALM 등)는 `audit_admin_access`로 남는다 | C-10, C-30 | **해소(2026-11-24)**: login-history·audit 조회와 `/internal/admin/dr/monitor/sample` 쓰기가 감사 행을 남긴다(C-34). 관리자 쓰기의 이중 승인은 여전히 없다 |
| T-03 | 저장소에 비밀이 커밋된다 | `.env` 무시, 자격증명 패턴·하드코딩 리터럴 스캔 | C-31, tests/test_m8_secret_hygiene.py | git 이력 전체 스캔은 하지 않았다(`.env`가 이력에 없음만 확인). 패턴에 없는 형식의 비밀은 놓칠 수 있다 |
| T-04 | 오류 응답·로그로 비밀이 샌다 | 응답·로그 호출 인자에 비밀 변수명을 넣지 않는지 정적 검사. DB 편집기는 비밀 열을 가리고 감사 페이로드에도 값이 없다 | C-31, tests/test_pg_db_editor_secrets.py | **해소(2026-11-24)**: DB 오류는 일반 메시지와 요청 번호만 응답하고 상세는 서버 로그에 남는다(C-35). 검증용 `ValueError` 메시지는 의도된 업무 오류 코드라 그대로 나간다 |
| T-05 | 복구 훈련용 비밀번호가 프로세스 목록에 보인다 | pg_restore 비밀번호는 환경변수로 전달 | tests/test_m8_restore_cleanup_unit.py | 환경변수도 같은 계정의 다른 프로세스가 읽을 수 있다 |
| T-06 | 백업이 깨져서 복구를 못 한다 | 격리 DB 복원, 필수 표·외래키·통합 대사 점검, 임시 DB 정리 보고 | C-13, docs/m8_records/drills.json | 통합 대사 통과 기록 없음(2026-11-21 시도는 스키마 불일치로 실패). 백업 최신성은 화면에서 조회 전용으로 경고한다(C-37, 기준 48시간). 백업을 주기적으로 만드는 일정 자체는 이 저장소가 보장하지 않는다(**미비**). 서비스 기동·전체 복구 시간은 측정하지 않았다 |
| T-07 | 시장 충격 뒤 장부가 어긋난다 | 통합 대사와 분개 대차 검사. 금리 급등, 예금 인출, 상관 부도, 담보 하락, 환율 급변, 결제 실패 6개 시나리오 | C-32, tests/test_m8_stress_scenarios.py | 소규모 시험 DB 기준이다. 운영 규모의 부하와 시간은 검증하지 않았다 |
| T-08 | 시험이 운영 DB를 건드린다 | 시험 중 기본 DB 디렉터리 격리 | C-14 | 운영 PostgreSQL DSN 자체의 격리는 환경 설정에 의존한다 |
| T-09 | 관리자 계정이 탈취된다 | 로그인 기록(로그인 서버가 남김). 4312/4313 의 별도 관리자 로그인 관문은 2026-11-22 삭제 | 일부(login-history) | **미비**: 다중 인증, 관리자 세션 만료·재인증 시험, 이상 접근 경보. 부트스트랩 관리자 ID는 설정으로 바꿀 수 있다(C-36, 기본값은 기존 계정). 운영 환경에서 별도 값을 설정했는지는 확인하지 않았다 |
| T-10 | 관리자 권한이 오래 남는다 | 수기 접근 검토 1회(2026-11-21) | docs/m8_records/drills.json | 정기 검토 절차(docs/m8_access_review_procedure.md)와 기록 도구(tools/access_review.py), 35일 기한 경고가 있다(C-37). **미비**: 권한 변경 승인 기록과 관리자 쓰기 이중 승인은 없다 |
| T-11 | 내부 토큰이 약하거나 비어 있다 | 서버는 토큰이 비면 모든 POST를 401로 거절하고 `hmac.compare_digest`로 비교한다 | tests/test_m8_secret_hygiene.py(환경변수 사용 확인) | **미비**: 토큰 길이·교체 절차 시험이 없다 |
