# LAPLACE 금융 시뮬레이터 현실화 계획

## 목표와 범위

내부에서만 동작하는 현실성 높은 금융 시뮬레이터를 만든다. 기존 데이터와 기능을 우선 재사용한다. 실제 은행·수탁기관·세무기관 연결, 실제 KYC 자료 수집, 외부 인증 취득은 범위 밖이다. 기준금리 결정권은 관리자에게 둔다.

## M4 — #74 상품화폐 회계 완료 기준

- [x] 금액 필드 등록부, 행 단위 최소단위 snapshot, 미분류 스키마 감사 및 관리자 통합 대사 연결. 이 검사는 소비자 코드 전체 계보를 증명하지 않는다.
- [ ] 상품통화 최소단위/Decimal 경계를 모든 거래 consumer에 적용한다. 표준·외화 증권 주문, 옵션 주문 예약·매칭·환불은 연결했다. 선물, 채권/회사채, 대출 생애주기, 담보처분, 레거시 표시·저장 경로가 남았다. 옵션은 기준통화만 허용하고 기준통화는 0자리다.
- [ ] 고객·기관·회사·세금·시장·펀드·대출·채권 간 원금·현금·수수료·세금·손익을 실제 업무 전기와 연결한다. 시장/기관 clearing, FX clearing, 일부 법인·펀드·세금 경로가 남았다.
- [ ] 모든 보조원장을 계정 매핑과 함께 공통 전기에 연결하고 통화·정밀도별 시산표를 대사한다. 현재 통합 보고서는 구현된 검사만 집계한다.
- [ ] 기존 잔액은 근거가 있는 범위에서 재구성하고, 불가능한 과거는 명시 baseline으로 분리한다. 업무별 rollback·재실행 멱등성·마감·정정 통합검증이 남았다.
- [ ] 전체 금액 계보·보조원장 대사·스트레스 및 close 게이트를 실행하고 제한을 문서화한다.

옵션 주문 후속으로 옵션 매칭·예약금을 `limit_price_minor_units`/`reserved_cash_minor_units`에 연결하고 `market_order_reservations`에서 검사한다. 타깃 옵션/저장 회귀 4건 및 통화 저장·주문 대사 33건이 통과했다. 이는 옵션 premium 체결 이벤트·지갑 링크와 계약/담보/행사/만기 원장 대사를 완료한 것이 아니다. 현 단계 M4 전체 완료 판정은 보류한다.

## 후속 단계

### M6 — 조달·금리·Basel·ALM

1. 은행채·은행간·RP·중앙은행 조달과 만기/담보/가격/한도를 원장화한다.
2. FTP와 예금 행동만기·금리베타를 상품 가격에 연결하고 시장·기대 입력으로 곡선/선도금리를 만든다.
3. CET1/AT1/Tier 2, 완충자본, 관할별 RWA·레버리지, HQLA·LCR·NSFR를 구현한다.
4. 담보·유동성·행동만기를 반영한 ΔNII/ΔEVE와 경계 테스트를 추가한다.

### M7 — 계약·법률·회수·시장·FX

1. 혼합/단계 금리, fixing·고지·부분상환·한도대출을 보강한다.
2. 준거법·고객/상품 유형·관할·계약일별 최고금리, APR, 세금 규칙을 구성한다.
3. 연체 waterfall, 채무조정·파산·회수곡선·NPL과 채권자 우선순위를 연결한다.
4. 예금보험기금/정리, 채권 위험지표·파생/헤지, 통화별 ALM·환위험을 검증한다.

### M8 — 보안·준법·완료 검증

1. 내부 위협모델, 최소권한, 비밀관리, 접근/변경 감사, 백업·복구와 보존정책을 검토한다.
2. KYC·AML은 내부 정책·사례관리로 한정하고 실명자료나 외부 제재목록 연동은 두지 않는다.
3. 규제 통제-증빙표와 사고/복구 훈련 기록을 준비한다. 실제 인증 취득은 완료조건이 아니다.
4. 금리급등·예금인출·상관부도·담보하락·환율급변·결제실패 복합 스트레스에서 회계 불변식을 검증한다.
5. 금액 정밀도, 전 원장 대사, 국가별 법률/APR/세금, 권한·불변 이력의 전체 통합 게이트를 통과시킨다.

## #80 종료 범위

#80은 내부 시뮬레이터 범위에서 완료다. HTS 의결권 위임/투표, DR 수탁 요청·예약·지연·수수료·재시도/만료, 세무거주지 스냅샷, 국가별 배당 원천징수, 불변 이벤트·내부 복식분개 및 관리자 대사를 포함한다. 실제 수탁/예탁/은행/세무기관 연결, 신분·거주지 증빙, 법적 조약 판정과 외부 송금은 제외한다.

## 완료 판정

각 단계는 코드와 migration, 사용자/관리자 웹 접근, 권한·감사, 원장 대사, 실패·재실행 경계, 해당 회귀 및 전체 통합 검증을 확인한 뒤에만 완료로 표시한다. proxy와 내부 가정은 규제 산식·실증 결과로 표현하지 않는다. 과거 이벤트가 없어 재구성할 수 없는 잔액은 거래를 꾸며내지 않고 baseline으로 보존한다.
