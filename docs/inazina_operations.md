# Inazina 운영 안내

운영 DB는 `database/inazina.db` 하나다. 통합된 기존 `users.db`, `accounts.db`, `assets.db`, `product.db`, `company.db`, `pot.db`, `tax.db`, `system.db`는 무결성·이전 기록 검증 및 복구 ZIP 생성 후 정리한다. 이전 기록도 ZIP에 보존하며 별도의 기록 전용 DB는 정리 대상에서 제외한다. DB Browser는 **inazina.db**를 열어야 한다. 파일명과 작업 폴더명은 별개이므로 기존 프로젝트 폴더를 옮길 필요는 없다.

## 관리자 명령어

DB `users.role=admin`만 `$` 명령어에 응답한다. 일반 사용자의 입력은 메시지 전송·삭제 없이 무반응이다. 관리자는 서버 채널에 입력한 명령의 결과를 개인 DM으로 받은 뒤 원래 채팅을 삭제한다. DM에서 직접 입력한 `$` 명령은 삭제하지 않는다. DM에서 인증 코드나 추가 확인 문구를 입력할 필요는 없다. 명령어·버튼은 실행자에게만 연결되고 저장 시 관리 권한이 유지되는지 확인한다. 봇의 Message Content Intent와 서버 메시지 관리 권한, 관리자의 DM 허용이 필요하다. DM을 전달할 수 없으면 작업을 실행하지 않는다.

`$도움말`과 `$help`는 관리자 명령어와 국가 명의 기능을 함께 안내한다. 기존 `$stock`, `$asset`, `$etf`, `$future`, `$corporatebond`, `$fund`, `$indexfund`, `$commodity`, `$bond`, `$saving`, `$loan`, `$option`, `$currency`, `$fxproduct`, `$catalog`, `$국고`, `$user`, `$volatility`, `$settings`, `$setup`, `$register`와 이전 별칭은 더 이상 등록하지 않는다.

| 명령어 | 인자·용도 |
|---|---|
| `$상품수정` | `[id] [상품종류] [유형별 순서형 인자 ...] [추가 JSON(선택)]` · 상품 설정 전체 수정 |
| `$상품가격수정` | `[종목id] [add/del/modify] [금액]` · 가격 더하기/빼기/지정값 |
| `$상품생성` | `[id] [상품종류] [유형별 순서형 인자 ...] [추가 JSON(선택)]` |
| `$상품삭제` | `[id]` · 기록을 보존하고 거래 중지; 미체결 주문·계약 의무는 먼저 정리 |
| `$기본소득` | `[금액]` · 국고에서 시민에게 지급 |
| `$사건` | 인자 없이 실행 → DM 버튼 → 상품코드·호악재·duration·변동률·선택 목표금액 모달 |
| `$잔고수정` | `[user_id/계좌번호] [add/del/modify] [금액]` · 사용자 지갑 또는 일반/외환통장 잔고 |
| `$등록` | `[user_id]` · 시민 등록 |
| `$도박확률` | `[0~100]` |
| `$도박리턴값` | `[리턴 퍼센트]` |
| `$시장분위기` | `[bull/flat/bear]` |
| `$상품분위기` | `[종목id] [bull/flat/bear]` · 자동 가격 종목의 개별 흐름 |
| `$복권당첨번호보기` | 현재 지정 번호 또는 직전 추첨 번호를 관리자에게 표시; 자동 번호는 추첨 시 결정 |
| `$복권당첨번호변경` | `[번호 6개] [보너스(선택)]` · 현재 미추첨 회차 지정. 보너스를 생략하면 남은 번호에서 무작위 선택 |
| `$세율` | `[퍼센트]` |
| `$환율수정` | `[외화A] [외화B] [비율]` · 1 A = 비율 B. B 시세 유지, A 시세를 정수 NWX로 반올림 |
| `$복권가격설정` | `[가격]` · 다음 개설 회차부터 적용 |
| `$금리수정` | `[add/del/modify] [수치]` · 기준금리, 연 퍼센트 |
| `$법정이자수정` | `[add/del/modify] [수치]` · 법정이자, 연 퍼센트 |

```text
$상품생성 NEW company "새 주식" 게임 100000000 100000 1000 INZ
$상품가격수정 NEW add 100
$상품삭제 NEW
$잔고수정 123456789 modify 1000000
$환율수정 USD EUR 0.9
$금리수정 modify 3
$법정이자수정 modify 5
```

생성 유형은 `company`(주식, `stock` 별칭도 지원), `asset`(시장 자산), `etf`, `future`(주식 선물), `corporatebond`(회사채), `fund`(일반 펀드), `indexfund`, `commodity`(현물 원자재), `bond`(국채), `saving`(저축), `loan`(대출), `option`, `currency`(통화), `fxproduct`(외환통장)다. 한글 유형도 지원한다. 두 번째 인자인 상품종류에 따라 이후 인자의 이름과 순서가 달라진다. 공백이 있는 이름·문자열은 따옴표로 묶는다. 마지막 추가 JSON은 선택 사항이며 `quote_currency`, `is_fixed` 등 기본 인자 외 설정을 지정할 때만 사용한다. 이미 입력한 기본 인자를 JSON에서 중복 지정할 수 없다. 이전 key=value·전체 JSON 입력은 호환용으로만 유지한다.

```text
$상품생성 SAV saving "새 적금" 3 1000 30 86400 1 Inazina
$상품생성 USDACC fxproduct "달러통장" USD 1
$상품생성 CALL1 option INZST001 call 1500 30 1 100 50
```

옵션 생성은 국가의 담보가 필요하다. 기존 상품의 결제 통화와 발행된 파생·채권 계약 조건은 변경하지 않는다. 가격 없는 저축·대출 상품에 `$상품수정`으로 가격을 부여할 수 없다. GARCH 세부 설정·신용·국적 등 별도 명령이 없는 설정은 DB Browser에서 관리한다. 모든 변경과 국가 거래는 `admin_audit`에 기록하며 비밀번호는 기록하지 않는다.

## 국가 명의 거래

지원 기능은 `$계좌개설`, `$계좌해지`, `$내지갑`, `$내주문`, `$대출`, `$대출연장`, `$대출상환`, `$도움말`, `$매도`, `$매수`, `$선물증거금`, `$송금`, `$옵션작성`, `$옵션체인`, `$주총`, `$펀드가입`, `$펀드환매`, `$환전`이다. 관리자가 아닌 국가 `users.user_id=__treasury__`의 잔액·보유자산·담보로 실행한다. 국가는 일반 사용자와 같은 거래소에서 거래한다.

조회는 DM으로 바로 표시한다. 입력이 필요한 기능은 인자 없이 실행하면 DM 버튼과 입력 모달을 제공하며, 일반 기능은 모달 순서와 같은 인자를 채팅에 입력해 실행할 수도 있다. `$주총`은 인자 없이 실행한 뒤 DM 모달을 사용한다. 예: `$매수 INZST001 2 1200`, `$송금 수신자 1000`, `$환전 NWX USD 10000`. 국가와 일반 사용자 모두 지갑 조회 이름은 `내지갑`이다.

## 상품 카테고리와 그래프

`/검색`의 첫 화면은 **메인**이며 카테고리와 카테고리별 종목 수만 표시한다. 주식·ETF·국채·회사채·주식 선물·원자재 선물·일반 펀드·인덱스 펀드·현물 원자재·옵션·외환·외환통장·저축·대출상품을 개별 카테고리로 조회한다. 전체요약·주식 외 투자상품·내 통장·보유자산·개인 대출 카테고리는 제거했다. `/국채` 목록은 `/검색`의 국채 카테고리로 통합했다.

기본 상품은 각 카테고리 50개, 총 650개다. 여기에 외화 결제 주식·현물 원자재 100개를 별도로 추가한다. 모든 이름·가격·환율은 게임용 설정이다. 기본 옵션 50개는 국고가 작성한 커버드 콜이며, 각각 담보 주식 100주와 매도 호가가 있다. 새 상품이 추가될 때 기존 사용자의 잔액·상품 설정을 덮어쓰지 않는다. 기존 코드가 기본 코드와 충돌하면 일괄 추가를 중단하고 전체를 롤백한다. 기본 발행은 국가가 새 주식을 발행하는 게임 내 상장이며 현실 상품의 권리를 나타내지 않는다.

`/그래프 종목:INZOP001`처럼 첫 번째 인자에 종목 코드를 반드시 입력한다. 종목 선택 셀렉박스와 자동완성은 사용하지 않는다. `/매수`·`/매도`·`/호가`·`/선물증거금`·`/펀드가입`·`/펀드환매`·옵션 기초주식도 코드를 직접 입력한다. 코드는 `/검색`에서 확인한다. 금리는 `기준금리`·`법정이자`를 입력할 수 있다. 옵션과 국채는 거래가 없더라도 현재 시세를 매초 기록한다.

| 그래프 선택 | 캔들·집계 주기 | X축 총 표시 기간 |
|---|---|---|
| 1분 | 1분봉 | 10분 |
| 5분 | 5분봉 | 1시간 |
| 10분 | 10분봉 | 6시간 |
| 30분 | 30분봉 | 12시간 |
| 1시간 | 1시간봉 | 1일 |
| 6시간 | 6시간봉 | 1일 |
| 12시간 | 12시간봉 | 1일 |
| 1일 | 일봉 | 1일 |

선택값은 OHLC·거래량·지표의 집계 주기이며, X축은 위 표의 총 표시 기간만큼 보여준다. 선택 메뉴 설명과 그래프 임베드에도 해당 총 기간을 함께 표시한다.

한국시간 날짜가 바뀌면 과거 가격/거래/지수 로그는 정리하며, 잔액·주문·계약·금리 이력·환전 거래 원장·복권 기록은 보존한다. 따라서 6시간·12시간·1일 그래프에서도 당일 저장된 기록만 표시될 수 있다.

## 사건과 가격

`$사건` 버튼은 종목, duration(초), 호재/악재, 0~100%, 선택 목표가격의 다섯 항목을 가진 모달을 연다. 목표가격이 없으면 시작가에서 호재 +N%, 악재 -N%를 최종 목표로 잡는다. 목표가격을 입력하면 %는 중간 흔들림의 강도다.

가격은 시작가와 목표가를 잇는 평균 변화율 선을 기준으로 위아래로 움직인다. 변동률이 클수록 기준선 주변의 편차가 커지며, 시작·종료 지점에서는 편차가 줄어들어 종료 시점에 정확히 목표가격을 적용한다. 반올림으로 아주 작은 가격 차이는 같은 호가로 보인다. GARCH 분산·공통 요인·자산별 충격·중복 틱 방지·재시작 복구는 유지한다.

같은 종목에 사건을 다시 등록하면 **기존 사건을 superseded로 중단하고 등록 순간의 현재가에서 새 duration·목표로 시작**한다. 다른 종목의 사건은 계속된다. 사건 기록은 삭제하지 않는다. 가격 고정 종목과 만료 상품은 제외하며, 옵션·국채는 계약상 가격 고정과 시장 프리미엄을 구분하여 개별 사건을 허용한다. ETF·선물·회사채·펀드도 개별 사건을 허용한다. 전체 시장 사건에서는 기존과 같이 독립 가격 종목을 대상으로 하며, 연결 상품은 기초 종목 변동을 반영한다.

사건은 채권 액면가·상환액, 옵션 행사가·담보를 변경하지 않는다. 지수/NAV 연동 상품은 사건 종료 후 기본 평가식으로 돌아가며, 옵션/국채의 사건 시장가격은 후속 사건 또는 거래/운영 변경 전까지 유지할 수 있다.

## 외환

`currencies`, `country_currencies`, `fx_products`, `fx_accounts`, `fx_transactions`가 동일 DB에 저장된다. 낙원의 기본 통화는 NWX이며 미국→USD, 대한민국→KRW 등은 **게임 설정**이다. 45개 가상 국가와 통화를 함께 준비했다. 기존에 통화가 매핑되지 않은 국적은 NWX를 기본으로 표시한다. 국적·통화 연결과 사용자 국적은 DB Browser의 `country_currencies`·`users`에서 관리한다.

```text
/검색
/내지갑
/계좌개설 상품:INZFX001
/송금 수신자:본인_USD_외환계좌번호 금액:15000 출금계좌:__wallet__
/환전 출금통화:USD 입금통화:EUR 금액:1
/송금 수신자:본인_사용자_ID 금액:1 출금계좌:본인_USD_외환계좌번호
/내지갑
/그래프 종목:FX_USD
```

출금/입금 통화의 외환통장은 먼저 개설한다. NWX는 정수, 외화는 소수점 6자리까지 지원한다. 1외화 단위당 NWX 시세가 실시간으로 움직이며, `$사건`의 `FX_USD` 같은 종목으로 환율 목표를 지정한다. 환전 중 사용한 두 시세, 수수료, 차감·입금액은 하나의 트랜잭션에 저장한다. 잔액 부족이나 통장 미개설이면 모두 롤백한다. 같은 통화 환전은 거부하며, 입금액은 내림·수수료는 올림하여 반올림 차익을 막는다.

환전 수수료 기본값은 0.1%이고 국고에 입금된다. 외환통장은 상품 연이율에 따라 잔액을 늘리며 1마이크로 단위 미만 이자는 누적한다. `/내지갑`의 외환 평가액은 현재 환율을 적용한다. `/외환계좌`는 `/계좌개설`에 통합했고 상품 코드를 직접 입력한다.

외화 결제 주식 50개와 현물 원자재 50개를 추가했다. USD·EUR·JPY·GBP·KRW마다 각각 10개씩이며 `INZUSDST001`은 USD 주식, `INZUSDCM001`은 USD 현물 원자재다. 해당 통화의 외환통장을 먼저 개설하고 잔액을 준비한 뒤 `/매수`·`/매도`에서 거래한다. 지정가는 종목의 결제 통화 단위이며 NWX 지갑을 자동으로 사용하는 기능은 없다. 주문 예치·환불·체결 대금은 같은 외화로 처리하고, 순자산과 매도 실현이익 세금은 체결 시점 환율로 NWX 환산한다. 기존 상품은 NWX를 유지한다. 외화 결제는 주식·현물 원자재를 지원하며 옵션·주식 선물·회사채 발행은 NWX 기초주식만 지원한다. 결제 통화 `quote_currency`는 발행 후 변경할 수 없다.

`/외환입금`·`/외환출금`과 대응하는 `$` 명령어는 제거하고 `/송금`·`$송금`으로 통합했다. 수신자는 사용자 ID 또는 일반/외환 계좌번호, 출금계좌는 본인 계좌번호 또는 `__wallet__`이다. 금액은 **출금 통화 기준**이며 외화는 소수점 6자리까지 입력한다. 외환 송금에서 출금계좌를 비우면 NWX 지갑을 사용한다. 통화가 같으면 환전 수수료 없이 송금하고, 통화가 다르면 해당 시점 환율과 환전 수수료를 적용한다. 다른 사람의 출금계좌는 사용할 수 없고, 통장이 없으면 먼저 개설해야 한다. 일반통장 원금·이자 기준 시각도 함께 갱신하며 모든 차감·입금·수수료·원장을 원자적으로 처리한다.

`/내지갑`에 국적·기본 통화와 일반/외환통장 번호·외화 잔액·NWX 평가액을 함께 표시한다. 통장·보유 종목·작성 옵션이 많으면 페이지로 전부 조회한다. 기존 옵션·국적·외환 개별 조회는 `/내지갑`에 통합했고, 국가 지갑도 `$내지갑`으로 조회한다. `/환율`은 `/검색`의 **외환** 카테고리로 통합했다. 환율은 **1 NWX = 외화 금액**으로 표시하며 **10개 통화씩** 페이지를 넘긴다. 페이지 이동 시 최신 시세를 다시 읽으며, 표시 금액에는 환전 수수료를 포함하지 않는다. 예를 들어 1 USD가 1,600 NWX이면 1 NWX = 0.000625 USD다. DB의 시세와 사건 목표가격은 기존대로 1외화 단위당 NWX를 사용한다.

옵션 작성 의무 평가는 작성한 옵션의 현재 의무 가치로, 순자산에서 차감하므로 음수로 표시한다. 옵션 프리미엄을 거래해도 커버드 콜 담보 주식은 계약이 끝날 때까지 잠겨 있어 매도할 수 없다. 담보 주식은 실제 기초주식 코드와 잠금 계약 코드를 표시하고 작성 계약·체결 수량·미체결 수량·담보·만기를 함께 보여준다.

복권 사용·관리 명령어와 추첨 검증은 [복권 운영 안내](lottery_operations.md)에 정리했다. 관리자는 `$복권가격설정`, `$복권당첨번호보기`, `$복권당첨번호변경`을 사용한다. 다른 회차 규칙은 DB의 `settings.lottery_config`에서 관리한다.

## DB 운영

이전은 모든 테이블·행·인덱스·트리거·AUTOINCREMENT 값을 임시 파일에 복사하고 건수·무결성을 검증한 뒤 원자적으로 `inazina.db`를 공개한다. 실패한 이전은 기존 DB를 변경하지 않는다. 단일 파일의 WAL, 공유 쓰기 잠금, 원자적 거래와 50ms 시장 갱신 대기를 사용한다. 외환 사용자/거래시간 인덱스와 기존 가격/거래 인덱스를 유지한다. 봇을 재시작하여 새 코드와 슬래시 목록을 적용하고, 이후 DB Browser도 새 파일만 편집한다.

실제 Discord의 버튼/모달 제출, Message Content Intent와 삭제 권한은 서버에서 확인해야 한다. 재시작 후 봇 사용자 이름도 Inazina로 변경을 시도하며, Discord가 제한하면 로그를 남기고 운영을 계속한다. 토큰은 `INAZINA_TOKEN` 환경변수를 사용하며, 기존 `NACONOMICS_TOKEN`도 이전 호환을 위해 지원한다.

## 내지갑 화면

`/내지갑`은 메인에서 국적·기본통화·현금·통장·외환·투자 평가액·주문 예치금·옵션 담보·옵션 작성 의무 평가·부채·순자산·신용점수와 카테고리별 항목 수를 보여준다. 선택 메뉴에서 통장·외환통장·주식·ETF·국채·회사채·선물·펀드·원자재·보유 옵션·작성 옵션·옵션 담보·대출을 나눠 보고, 10개씩 페이지를 넘긴다. 가격·잔액은 조회 시점 스냅샷이며 최신 값은 명령어를 다시 실행해 확인한다.

옵션 작성 의무 평가 박스는 메인과 작성 옵션 화면에 표시한다. 미만기 판매 옵션의 현재 프리미엄 × 미만기 체결 계약 수이며 순자산에서 차감한다. 만기에 이 평가액을 그대로 납부하는 의미는 아니다. 콜이 행사되면 담보 주식을 인도하고 행사가 대금을 받으며, 풋이 행사되면 담보금으로 행사가에 주식을 매수한다. 미행사 잔여 담보는 반환하고 이미 수령한 프리미엄은 유지한다. 매수 옵션을 재판매한 사용자는 작성자 의무가 생기지 않는다.

지갑 메인의 금액·신용점수는 코드 박스로 통일한다. 보유 카테고리는 통장·주식/ETF·채권·선물·펀드/원자재·옵션·대출 그룹의 아이콘과 보유 건수를 인라인 필드로 표시한다.

관리자 `$` 응답은 도움말·처리 중·결과·오류·모달 안내를 임베드로 통일한다. 성공은 초록색, 오류는 빨간색, 안내는 파란색으로 표시하고 긴 결과는 임베드 미리보기와 전체 텍스트 첨부 파일로 제공한다.

관리자 도움말은 상품·시민/잔고·시장/환율·도박/세금·금리·복권·사건·국가 기능을 별도 임베드 필드로 나눈다. 일반 응답은 처리 상태·명령어·상세 내용으로 구성하고 가격·잔고 변경은 대상과 변경 전후 금액 박스를 표시한다.

## 상품생성 인자 순서

공통 앞부분은 `$상품생성 [id] [상품종류]`이며, 아래 인자를 순서대로 입력한다. 마지막 `[추가 JSON]`은 모든 유형에서 선택 사항이다.

| 상품종류 | 순서형 인자 |
|---|---|
| `company` | `name` → `industry` → `capital` → `total_shares` → `share_price` → `exchange_id` |
| `asset` | `name` → `type` → `price` → `total_supply` → `exchange_id` |
| `saving` | `name` → `interest_rate` → `deposit_amount` → `maturity_days` → `interest_cycle` → `compound_type` → `issuer` |
| `loan` | `name` → `interest_rate` → `loan_limit` → `maturity_days` → `interest_cycle` → `min_credit_score` → `issuer` |
| `etf` | `name` → `unit_price` → `total_supply` → `underlying_exchange_id` → `leverage_multiplier` → `rebalance_cycle_seconds` → `exchange_id` |
| `future` | `name` → `unit_price` → `total_supply` → `underlying_code` → `maturity_days` → `contract_size` → `initial_margin` → `maintenance_margin` → `exchange_id` |
| `corporatebond` | `name` → `unit_price` → `total_supply` → `issuer_code` → `face_value` → `annual_rate` → `maturity_days` → `exchange_id` |
| `fund` | `name` → `unit_price` → `total_supply` → `components` → `exchange_id` |
| `indexfund` | `name` → `unit_price` → `total_supply` → `underlying_exchange_id` → `exchange_id` |
| `commodity` | `name` → `unit_price` → `total_supply` → `exchange_id` |
| `bond` | `name` → `market_price` → `total_supply` → `face_value` → `annual_rate` → `maturity_days` → `exchange_id` |
| `option` | `underlying_code` → `option_type` → `strike_price` → `maturity_days` → `quantity` → `limit_price` → `volatility_percent` |
| `currency` | `name` → `asset_code` → `nationality` |
| `fxproduct` | `name` → `currency_code` → `annual_rate` |

`compound_type`은 0=단리, 1=복리이고 `interest_cycle`은 초 단위다. 펀드 `components`는 `INZST001:0.5,INZST002:0.5`처럼 입력하며 비중의 합은 1이다.

```text
$상품생성 FIX company "고정 주식" 게임 100000000 100000 1000 INZ {"is_fixed":1}
$상품생성 FUND fund "혼합 펀드" 1000 10000 INZST001:0.5,INZST002:0.5 INZ
```

`add`는 현재값에 value를 더하고, `del`은 현재값에서 value를 빼며, `modify`는 현재값을 value로 설정한다. 값이 허용 범위를 벗어나면 변경하지 않는다. `$도움말`/`$help`는 상품·시민/잔고·시장/환율/사건·도박/세금·금리·복권·국가 기능의 7개 상세 페이지와 첫 메인 페이지를 선택 메뉴와 이전/다음 버튼으로 조회한다.

`$도움말`의 첫 페이지는 **메인**이며 카테고리 목록만 표시한다. 카테고리를 선택하거나 다음 버튼을 누르면 명령어·인자 설명을 확인한다.
