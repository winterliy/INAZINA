## 기업·주식·지배구조 기획

### 목적과 결정 사항

이 문서는 2026-11-01 대화에서 정리한 기업 구조 및 주식 권리 설계를 기록한다. 현재 `company` 테이블은 회사 정보와 주식 발행 정보를 함께 가지며, `share_class`의 `common`/`preferred` 구분과 우선주 조건이 이미 일부 구현되어 있다. 법인 계정은 보통주 발행 법인을 중심으로 연결된다. 장기적으로 기업과 주식 발행을 분리하되, 기존 기능과 데이터를 한 번에 교체하지 않고 단계적으로 이전한다.

확정·보류 결정:

- 비영리법인과 공기업 분류를 기업 프로필의 확장으로 기획한다.
- 영리법인의 법적 형태(유한회사·유한책임회사·합명회사·합자회사)는 보류한다. 현행 주식회사 구조를 유지한다.
- 기업 규모는 `중소기업 / 중견기업 / 대기업` 세 구간으로 한다.
- 기업 규모는 지표로 자동 판정하되 관리자가 지정할 수도 있게 한다.
- 환산액·환산 기준일처럼 현재 값에서 산출 가능한 임시·파생 데이터는 코드 전체를 조사해 저장을 없애고 즉시 계산할 수 있는지 검토한다. 감사·재현·계약상 필요한 사건 시점 값은 보존한다.
- 주식 권리는 회사가 아니라 회사 아래의 주식 발행 종류마다 설정한다. 보통주·우선주를 서로 다른 기업 유형으로 취급하지 않는다.
- 기업집단과 지배관계는 별개다. 지분이 없어도 집단에 속할 수 있고, 집단 소속만으로 자회사나 연결 회계로 판정하지 않는다.

### 1. 기업과 주식 발행 분리

#### 기업

기업은 정체성과 공통 운영 주체다. 이름, 국가, 산업, 상태, 법인 계정, 회계·재무제표, 기업 규모, 공공성, 기업집단 소속을 가진다. 비영리 조직도 계정·현금·예금·대출·송금·회계 화면을 가능한 한 공통으로 쓴다.

#### 주식 발행 종류

기업 아래에 0개 이상의 주식 종류를 둔다. 예: `Class A`, `Class B`, `Class C`, `우선주 1종`. 종류 이름은 임의 명칭이며 이름만으로 권리를 추정하지 않는다. 각 종류는 독립된 발행량·보유량·주가·거래코드·상장 상태를 가질 수 있다. 상장되지 않은 주식도 주식 발행으로 표현하며, 비상장 여부와 비주식 회사 여부를 혼동하지 않는다.

각 발행 종류에 설정할 권리:

- 의결권: 주당 의결권 수(0 포함), 의결권 행사 제한 및 적용 범위
- 배당: 무배당·고정액·비율, 우선순위, 누적 여부, 기준 금액
- 청산: 우선순위, 배분 배수/금액, 참여 여부
- 전환·상환: 허용 여부, 비율·조건·기한 및 만기 처리
- 양도·시장: 공개 거래, 비상장 양도, 보유자 제한 등
- 발행: 총 발행 가능 수량, 현재 발행 수량, 발행가, 발행·소각 기록

초기에는 기존 회사·상품·보유 테이블과 거래 코드의 호환 계층을 유지한다. 기존 `company` 행은 기업과 기존 보통주 발행을 함께 나타내는 레거시 레코드로 보고, 기존 우선주 행은 같은 기업 아래 별도 발행 종류로 매핑한다. 기존 회사 코드나 거래 이력은 재사용·변경하지 않는다. 신규 테이블과 호환 뷰/어댑터를 도입한 뒤 읽기 경로, 관리자 기능, 거래 경로 순으로 전환한다.

### 2. 주식 권리, 지분과 지배력

경제적 소유권과 의결권은 서로 다른 지표로 계산한다.

- 경제적 지분율은 해당 발행 종류의 소유 수량과 경제적 권리(예: 전환/배당/청산 참여 설정)를 바탕으로 계산한다.
- 의결권 비율은 각 주식 종류의 주당 의결권과 행사 자격을 반영한다.
- 회사 지배 판정은 의결권 비율을 우선 사용한다. 임계치, 공동 지배, 유의미한 영향력, 판단 불가 상태를 명시적으로 설정한다. 특정 임계치만으로 모든 사례를 법적 지배라고 단정하지 않는다.
- 자기주식은 경제적 소유와 의결권 분모에서 별도 정책에 따라 처리하고, 기본적으로 의결권을 행사하지 않는다.
- 의결권 없는 종류의 발행도 다른 종류의 주당 의결권 자체를 바꾸지 않는다. 다만 전체 의결권 분모가 바뀌어 기존 보유자의 의결권 비율이 희석될 수 있다.
- 우선 배당권은 배당 재원을 먼저 배분할 수 있지만 보통주 주당 배당 조건을 자동 변경하지 않는다. 총 재원과 종류별 순위에 따른 실제 배분은 함께 계산한다.
- 발행·소각은 해당 발행 종류만 수정한다. 메인 발행의 주가·수량·배당 조건을 직접 변경하지 않는다. 명시적인 전환·주식분할·자본변경만 여러 종류에 영향을 줄 수 있고, 영향 범위를 미리 검증한다.

발행 종류의 권리 변경은 이미 발행된 주식에 소급 적용하지 않는다. 권리 변경은 새 발행 조건으로 기록하고, 기존 주식은 별도 결의/교환 절차 없이는 기존 조건을 유지한다.

### 3. 지분도와 기업 간 지배관계 그래프

주식 보유 데이터에서 개인·법인 보유자를 노드로, 발행 종류별 보유를 방향성 간선으로 표현한다. 간선에는 수량, 경제적 지분율, 의결권 지분율, 주식 종류를 표시한다. 직접 보유와 간접 보유를 분리하고, 간접 보유는 각 지배 경로의 지분율 곱 및 합산 근거를 보여준다.

표시 범위 기본안:

- 특정 회사: 직접 주주를 표시하고, 지배 주체 방향과 자회사 방향은 기본 3단계까지 펼친다.
- 사용자: 사용자의 직접 보유 회사를 표시하고, 그 아래는 지배 관계가 확인된 경우만 펼친다.
- 기업집단: 지정 대표 기업을 중심으로 지배 연결을 강조한다. 집단 소속만 있고 지분 관계가 없는 기업은 별도 점선/소속 배지로 표시한다.
- 기본적으로 지배 연결을 펼치고 소수 지분 투자는 접는다. 깊이는 최대 5단계, 한 단계의 노드는 기본 20개로 제한하고 나머지는 개별 확장 가능한 “외 N개”로 접는다.
- 직접 지분은 기본 표시한다. 1% 미만 보유 숨김은 화면 옵션으로 제공하고, 합계·지배 판정 계산에서는 임의로 제외하지 않는다.
- 우선주나 특수 의결권은 종류별 권리 설정을 적용한다. 권리 데이터가 빠진 경우 지배 관계를 추정하지 않고 `판정 불가`로 표시한다.
- 순환 소유, 공동 지배, 다중 경로, 자기주식은 그래프에서 표시하며 순환을 무한히 펼치지 않는다.

### 4. 기업집단

기업집단은 법적 기업이나 지분 그 자체가 아니라 기업 간의 관리·브랜드·경제적 연계를 나타내는 묶음이다. 별도 집단 레코드에 이름, 관리자 지정 대표 기업, 설명, 상태를 두고 멤버십으로 기업을 연결한다. 멤버십에는 시작·종료 시점과 관리자 변경 기록을 남긴다.

기존 모회사·자회사 보유관계는 지분 데이터에서 계산하고, 기업집단 멤버십과 합치지 않는다. 집단 화면은 집단 내 직접·간접 지배 연결, 독립 계열사, 집단 밖 투자 관계를 다른 표시로 구분한다. 첫 단계는 수동 집단 구성과 조직도 표시로 한정하고, 연결 재무제표는 별도 기획·회계 검증 후 추가한다.

### 5. 기업 규모와 변경 공시

#### 구간과 자동 판정

표시 구간은 다음 세 가지다.

- 중소기업
- 중견기업
- 대기업

자동 판정 지표 후보는 매출액, 자산총액, 평균 종업원 수다. 자본금과 시가총액은 보조 정보로 둘 수 있지만 단독 기준으로 사용하지 않는다. 초기 출시 전 각 구간의 산식, 경계값, 지표 결합 방식(모두 충족/하나라도 충족), 국가별 기준 여부를 설정으로 확정해야 한다. 법률 기준을 표방하지 않는 게임 내 자체 분류라면 그 점을 UI에서 밝혀야 한다.

매출·자산이 서로 다른 통화인 경우 조회 시점 환율로 기준 통화 환산해 판정한다. 기업별로 환산액이나 환산 기준일을 영구 저장하지 않는다. 판정 결과 변경은 아래 공시 대기 정책을 적용한다.

#### 관리자 지정과 자동값

각 기업에 자동 판정값과 관리자 지정값을 분리해 둔다. 최종 표시값은 관리자 지정이 있으면 이를 우선하고, 없으면 자동 판정값을 사용한다. 관리자 지정 사유와 설정자·시각을 기록한다. 수동값을 해제하면 자동 판정으로 복귀한다. 대시보드에는 `자동 판정`, `관리자 지정`, `현재 표시`, 판정 지표를 함께 보여준다.

#### 변경 공시기간

관리자 설정으로 규모 변경 공시/대기기간을 둔다. 기본값은 제품 운영자가 정하며 아직 미확정이다. 0이면 즉시 반영한다. 자동 판정이 달라지면 새 후보값과 공시 예정 시각을 만들고, 기간 내 원래 값으로 돌아오면 후보 변경을 취소하거나 갱신한다. 적용·취소·관리자 즉시 적용은 감사 이력에 남긴다. 데이터가 불완전한 기업은 기존 표시값을 유지하고 `판정 자료 부족`을 표시한다.

### 6. 비영리·공공 부문 기업 분류

비영리성, 공공 소유, 기업의 법적 형태, 산업은 서로 다른 분류 축이다.

- `purpose`: 영리 / 비영리
- `ownership`: 민간 / 국가 소유 / 지방자치단체 소유 / 혼합 등
- `public_enterprise_type`: 해당 없음 / 공기업 / 시장형 / 준시장형 / 기타 공공기관 등
- `industry`: 기존 산업 분류
- `legal_form`: 현 단계에서는 기존 주식회사만 사용. 기타 영리법인 형태는 보류.

비영리 기업은 공통 계정·회계 화면을 사용하되 배당을 허용하지 않고, 잉여금의 목적사업 재투자 및 청산 잔여재산 제한을 둔다. 기부금·보조금·사업수익과 목적사업비·관리비 구분은 회계 확장으로 별도 설계한다. 공기업·시장형·준시장형은 법적 형태 대신 공공 소유와 운영 분류로 다루며, 실제 법령 기준을 적용할 때는 국가와 기준 시점을 명시한다.

### 7. 파생·임시 데이터 저장 최소화 조사

저장된 숫자·캐시 필드를 전수 조사해 다음 기준으로 분류한다.

1. **원천/상태 데이터:** 잔액, 체결가, 발행량, 계약조건, 수수료, 사건 시점 환율처럼 과거 사실과 재현에 필요한 값. 저장 유지.
2. **파생 표시값:** 현재 환율 환산액, 화면 합계, 현재 지분율 등 원천 데이터로 즉시 재현 가능한 값. 저장 제거 또는 조회 시 계산 검토.
3. **캐시:** 재계산 비용 때문에 유지하는 파생값. 무효화 기준, 최신성 보장, 원천 복구 절차가 있는지 확인하고 필요 없으면 제거.
4. **스냅샷/감사값:** 당시 공시·의결·정산·재무보고 값처럼 나중에 원천값이 변해도 역사적 결과를 보존해야 하는 값. 용도·보존 기간을 문서화하고 유지.

조사 산출물에는 테이블/컬럼, 읽기·쓰기 위치, 재계산식, 정밀도·성능 영향, 삭제/유지 근거, 마이그레이션 가능성을 기록한다. 우선 환산 기준일·현재 환산액, 중복 합계·가격 캐시부터 살펴본다. 운영 테이블을 조사만으로 삭제하지 않고 각 후보는 원천 복구와 동시성·정밀도 검증 후 개별 전환한다.

### 8. 단계별 구현 제안

1. **스키마 조사와 불변식 테스트:** 회사·우선주·보유·거래·배당·분할·재무의 의존관계를 맵핑하고 기존 종목의 동일성/원가/권리를 검증한다.
2. **기업 프로필 분리:** 조직 ID와 기업 공통정보를 도입하고 기존 회사 코드를 안정적으로 매핑한다. 기능 동작은 그대로 유지한다.
3. **주식 발행 종류 분리:** 보통주·현재 우선주 데이터를 발행 종류 레코드로 이전하고, 보유·주문·거래에 발행 종류 ID를 연결한다. 호환 어댑터를 통해 점진 전환한다.
4. **권리 엔진:** 의결권·배당·청산·전환 조건을 종류별로 계산한다. 발행·소각·배당·분할·합병의 영향 범위를 트랜잭션 전 검증한다.
5. **지분도/조직도 UI:** 직접 소유와 통제, 경제적 지분과 의결권, 집단 멤버십을 구분해 그래프로 표시한다.
6. **기업집단과 규모:** 멤버십 관리, 자동/관리자 규모 값, 공시기간 설정을 추가한다.
7. **비영리/공공 분류:** 배당·청산 통제와 목적사업 회계를 검증한 뒤 공개한다.
8. **파생 데이터 정리:** 전수 조사 결과에 따라 안전한 후보를 작은 단위로 전환한다.

각 단계는 기존 코드·티커·주문 이력·보유수량·평균원가·미지급 배당·기업 계정·재무제표를 보존해야 한다. 실패 시 해당 단계 전체를 롤백하고, 원본과 신규 표현의 대사 보고서를 남긴다.

### 9. 핵심 검증 시나리오

- 기존 보통주와 우선주를 이관해 코드, 보유자, 수량, 원가, 가격, 미체결 주문, 배당권이 변하지 않는다.
- 의결권 1/10/0인 세 종류에서 경제적 지분율과 의결권율이 서로 올바르게 다르다.
- 발행·소각은 지정된 발행 종류만 변경하고 다른 종류의 주당 가격·수량·권리를 직접 변경하지 않는다.
- 배당 우선순위가 있는 발행과 없는 발행이 총 재원 한도 안에서 올바르게 배분된다.
- 주식 분할·병합, 전환, 미체결 주문·담보·DR·ELS 등 연계 상태에서 안전하게 처리하거나 원자적으로 거부한다.
- 직접·간접 소유, 손자회사, 공동 지배, 순환출자, 자기주식, 비상장 종류, 1% 미만 보유가 그래프에 정확히 표시된다.
- 수동 기업집단 멤버십이 지배 판정이나 연결 회계를 자동으로 바꾸지 않는다.
- 통화 환율 변동으로 규모 자동 후보가 바뀌어도 공시기간 동안 표시값 정책이 일관된다. 수동 지정 해제는 자동값으로 돌아간다.
- 파생값 비저장 전환은 결과 정밀도, 역사적 보고서, 조회 성능과 복구 가능성을 보존한다.

- 기존 회사 코드와 거래 기록을 보존하는 `organizations` 및 `organization_share_issuances` 확장 테이블을 추가하고, 기존 회사/우선주를 시작 시 매핑한다. 관리자 화면에서 새 종류별 거래 코드와 주식 수·초기 가격·의결권·경제 지분 계수를 만들고, 종류 이름과 배당·청산 권리를 따로 관리할 수 있다. 신규 종류의 초기 주식은 거래소 국고의 매도 주문으로 등록한다. 유상·무상 신주 발행은 선택한 종류 코드만 변경하며, 종류 폐지는 보유자·주문·계약·미지급 배당이 모두 정리된 뒤 해당 종류만 비활성화한다. 거래는 호환용 레거시 종목에 연결되며, 보유·주문 테이블의 완전한 전환은 아직 끝나지 않았다.
- 관리자 API에서 기업 소유·공공기관 분류, 기업집단 생성과 소속, 규모 기준·공시기간, 규모 수동 지정, 발행 종류의 의결권·경제 지분 계수·배당·청산 권리를 관리할 수 있게 했다. 배당/청산 권리는 현재 거래 처리와 호환되도록 기존 주식 레코드에 반영하고, 발행 종류 메타데이터와 동기화한다.
- 자동 규모 값은 현재 회계 원장 매출·자산을 읽고 조회 시점 환율로 기준 통화 환산한다. 변환 금액/기준일은 저장하지 않는다. 현재 종업원 데이터가 없으므로 그 지표는 비워 두며, 기준이 설정되지 않았거나 자료가 없으면 `자료 부족` 상태다.
- 지분 그래프는 기존 보유 장부에서 직접 경제 지분과 의결권을 분리 계산한다. 기업 화면은 최대 5단계의 단순 주주 경로를 펼치고, 동일한 간선에 도달하는 다중 경로 기여분을 합산한다. 사용자 계정에는 직접 보유 종목과 의결권 과반 지배 기업 아래의 자회사를 표시한다. 이는 경로별 지분 기여 표시이며, 순환 출자까지 포함한 최종 법적 지배 판정은 아니다.
- 별도 관리자 화면 컴포넌트와 회원탈퇴 안내 인터랙션을 추가했다. 관리자 화면을 `기업 구조` 메뉴에 연결해 규모·공공 분류·발행 종류 권리·기업집단·지분 그래프를 열 수 있다.
- 비영리법인의 배당 금지·잔여재산 제한, 독립적인 기업 정체성으로의 완전 이전, 엄밀한 종류주식별 회계/의결 시스템, 법적 형태 확장은 아직 구현하지 않았다. 비영리 법적 형태는 현재 화면에서 선택할 수 없게 유지한다.

## 정식 액면분할 · 주식분할 · 액면병합

### 범위
기존 액면분할병합 명령은 가격·수량만 바꾼다. 이를 정식 액면분할, 일반 주식분할, 액면병합으로 구분하고 법인 자본 대시보드에 노출한다. 기존 명령은 호환 진입점으로 유지한다. 100만 이상 현재 25종목을 일반 주식분할로 약 10만에 맞춘다는 기존 요청도 유지한다.

### 의미와 데이터
- 정식 액면분할: 액면주식의 액면가를 1/N, 발행·상장·보유 수량을 N배로 바꾼다. 자본금은 유지하며 총 발행주식수 × 액면가 = 자본금을 검증한다. 회사의 현재 액면가, 통화, 정관 변경 및 특별결의 기록을 저장한다. 시장가격과 액면가는 별도 값이다.
- 일반 주식분할: 주당 시세를 1/N, 수량을 N배로 조정하며 자본금은 유지한다. 시장이나 국적만으로 무액면 여부를 자동 추정하지 않는다. 액면가가 존재하는 회사는 해당 주식 구조와 모순되지 않도록 검증한다.
- 액면병합: 가격·액면가(있다면)를 N배, 수량을 1/N로 조정한다. 자본금을 임의 감액하지 않는다. 초기 버전은 발행·상장·모든 보유수량이 정확히 나누어떨어져야 하며 단주가 생기는 경우 실행하지 않는다. 단주 현금청산은 별도 합의가 필요하다.
- 보통주·연결 우선주가 있는 경우 발행법인 전체의 액면·자본금 관계를 검증한다. 일부 클래스만 바꿔 불변식이 깨지는 요청은 거절한다.
- 기존 회사는 액면가 미설정 상태로 이관한다. 자본금을 주식 수로 나눈 값이 정수라는 이유만으로 법적 액면가를 자동 확정하지 않는다.

### 공통 불변식
보유자의 총 취득원가·지분율, 발행법인 자본금, 고정배당 총액을 보존한다. 주당 원가가 통화 최소단위보다 작아져도 lot 총원가를 유지하고 매도 시 배분한다. 가격·배당·청산가 반올림 기준 및 잔여는 기록한다. 소수점 수량은 정수로 잘라내지 않는다. 미체결·예약 주문과 DR·ELS·옵션·선물·회사채·담보 등 미지원 연결 상태는 사전 검증으로 거절하고 트랜잭션 전체를 롤백한다. 지수 기준·펀드 기준가격·시장 시뮬레이션 상태·이력도 같은 트랜잭션에서 조정한다.

### 정식 액면분할의 승인 방식 — 관리자 집행 중심으로 확정
사용자 결정: 주총은 의결만 하고 실제 집행은 관리자만 한다. 기존 소집 안내에 관리자 의결 결과·증빙 등록을 추가하고, 집행은 별도 요청에서 실행한다.
1. 관리자 증빙 등록: 정관 변경문서 및 특별결의 의사록을 참조하고 관리자가 확인해 실행한다. 실제 투표를 시스템이 검증한 것으로 표시하지 않는다.
2. 전자 투표: 기준일 주주명부·의결권·자기주식 제외·출석·찬반·특별결의 정족수·가결 후 실행·의결 기록 불변성을 구현한다. 실행 시 동일 결의를 중복 소비하지 않는다.

### UI
법인 자본 상세에서 세 방식 선택, 비율, 변경 전후 주가·발행/상장 수량·액면가·자본금·원가 보존 검증을 보여준다. 정식 방식에서만 법적 절차와 증빙/결의 필드를 요구한다. 확인창은 1주→N주 또는 N주→1주로 표시해 비율 방향을 혼동하지 않도록 한다.

### 검증
정수·소수점 보유, 최소단위 미만 취득원가, 부분상장, 고정·비율배당, 우선주 연결, 단주 병합 거절, 자본금 불변, 무권한·미승인·중복결의 실행 거절, 실패 전체 롤백, 일괄 분할 전후 통화별 평가액·총원가 대사, API 및 화면 왕복 검증.

### 현재 구현과 남은 일
기존 분할/병합의 누락 import, 소수점 수량 잘림, 상장수량·배당·청산가 조정 누락을 보완하고 대시보드 입력을 추가했다. 현재 원가 모형으로 총원가를 잃는 비율은 안전하게 거절한다. 정식 의결·액면가 모델과 관리자 집행, 유리수 총취득원가 보존·부분매도 배분을 구현했다. 소수점 보유의 원가도 분자/분모 문자열로 보존한다. 25종목 실제 일괄 분할을 완료했으며 발행·보유 수량, 총 취득원가와 자본금 보존을 검증했다. 지원하지 않는 분할 후 잔여원가의 옵션·DR·대출 담보·합병 경로는 명시적으로 거절한다.
