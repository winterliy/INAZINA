# 지갑·검색·그래프·대출 화면

`/내지갑`과 국가 명의 `$내지갑`의 메인은 현금·통장·투자 평가액·옵션 의무·총자산·부채·순자산·신용점수의 상단 정보 박스만 표시한다. 상세 보유 내역은 카테고리를 선택해서 확인한다. `$내옵션`과 `$내자산`은 사용하지 않는다.

`/검색`의 거래소 지수 카테고리에는 현재 지수와 그래프용 ID가 표시된다. 예: `/그래프 종목:__exchange_index__:INZ`. 기준금리·법정이자 카테고리에는 현재 연이율과 예약 ID `__rate__:base_rate`, `__rate__:statutory_rate`가 표시된다. 그래프 종목에 `기준금리`, `법정이자`를 직접 입력해도 된다. 우선주는 주식 목록에 우선주 표식을 보이고 의결권이 없는 상품으로 안내한다. 정기배당이 설정된 주식·상품은 주기와 주·좌당 배당금을 표시한다.

그래프의 시간 선택은 가로축 전체 폭이다. 1분=60초, 5분=300초, 10분=600초, 30분=1,800초, 1시간=3,600초, 6시간=21,600초, 12시간=43,200초, 1일=86,400초다. 조회 시점에서 해당 시간 전까지의 범위를 고정해 표시한다. 기록이 적어도 가로 폭을 줄이지 않으며, 일목균형표 미래 구름 때문에 폭을 늘리지 않는다. 이전 기록은 지표 계산에만 사용하고, 날짜별 기록 정리로 비어 있는 구간은 그대로 빈 공간이다.

`/대출 id:INZLN001`처럼 대출 상품 ID를 입력한 뒤 버튼의 금액 입력 창에서 신청한다. 검색 화면의 대출 신청 버튼도 상품 ID와 금액을 직접 입력한다. `/대출연장 id:13`은 `/내지갑` → 대출에 표시된 개인 대출 `#13`을 연장한다. 대출 상품의 연장 신용 기준과 허용 기간은 검색 화면의 대출 상품 목록에 표시되며, 등록되지 않은 연장 기간은 연장 불가로 안내한다. 국가 명의 기능은 `$대출연장 13`으로 실행한다.
