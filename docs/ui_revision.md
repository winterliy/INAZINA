# 지갑·검색·그래프·대출 화면

`/내지갑`과 국가 명의 `$내지갑`의 메인은 현금·통장·투자 평가액·옵션 의무·총자산·부채·순자산·신용점수의 상단 정보 박스만 표시한다. 상세 보유 내역은 카테고리를 선택해서 확인하며, 상세 카테고리에는 메인의 요약 박스를 반복 표시하지 않는다. `$내옵션`과 `$내자산`은 사용하지 않는다.

`/검색`의 거래소 지수 카테고리에는 현재 지수와 그래프용 ID가 표시된다. 예: `/그래프 종목:__exchange_index__:INZ`. 금리 카테고리에는 국적별 기준금리와 법정최고이자가 표시된다. 그래프 종목에 `기준금리`, `법정최고이자`를 직접 입력할 수도 있다. 우선주는 주식 목록에 우선주 표식을 보이고 의결권이 없는 상품으로 안내한다. 정기배당이 설정된 주식·상품은 주기와 주·좌당 배당금을 표시한다.

그래프의 시간 선택은 캔들·집계 주기다. 봉이 겹치지 않도록 주기마다 X축 총 표시 기간을 다르게 적용한다. 1분봉은 10분, 5분봉은 1시간, 10분봉은 6시간, 30분봉은 12시간을 표시하고 1시간봉·6시간봉·12시간봉·일봉은 1일을 표시한다. 일목균형표 미래 구름은 이 표시 범위를 늘리지 않으며, 그보다 이전 기록은 지표 계산 준비 구간으로만 사용한다.

`/대출 id:INZLN001`처럼 대출 상품 ID를 입력한 뒤 버튼의 금액 입력 창에서 신청한다. 검색 화면의 대출 신청 버튼도 상품 ID와 금액을 직접 입력한다. `/대출연장 id:13`은 `/내지갑` → 대출에 표시된 개인 대출 `#13`을 연장한다. 대출 상품의 연장 신용 기준과 허용 기간은 검색 화면의 대출 상품 목록에 표시되며, 등록되지 않은 연장 기간은 연장 불가로 안내한다. 국가 명의 기능은 `$대출연장 13`으로 실행한다.
