# Wide-Learning 통합본

두 스레드의 검토가 끝난 내용만 주제별로 정리합니다(RULES.md 2절 6단계). 사용자가 지정한 CLI 하나만 씁니다. 모든 문장 끝에 근거 항목 ID를 붙이고, 사실(`verified`)과 시뮬레이터 가정(`simulator-assumption`)을 구분합니다. `proposed`·`disputed` 상태의 내용은 넣지 않습니다.

작성 예:

```markdown
## T-04 개인 신용평가와 연체정보

### 확인된 사실
- 개인신용평가에서 상환이력 정보의 반영 비중이 가장 크다. [C-009]

### 시뮬레이터 가정
- 연체 1회 −35점, 반감기 14일. 실제 보존기간을 게임 속도에 맞춰 압축했다. [G-012]

### 결론 없음 (사용자 판단 필요)
- (disputed 항목 ID와 쟁점 한 줄)
```
