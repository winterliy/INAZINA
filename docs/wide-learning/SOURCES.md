# 자료 등급과 출처 검증

## 등급

| 등급 | 뜻 | 예 | 쓰임 |
|---|---|---|---|
| **S1** 1차·공식 | 규칙·통계·기준을 직접 만들거나 발표한 기관의 원문 | 중앙은행 발표·통계, 법령 원문, 국제기준서(BIS·IFRS), 감독기관 규정·보도자료, 국가통계 | `verified`의 필수 근거 |
| **S2** 전문·2차 | 전문가 검토를 거쳤거나 1차 자료를 명시적으로 인용하는 자료 | 국책·민간 연구기관 보고서, 학술논문, 대학 교과서, 업계 기관이 공개한 설명 자료, 각주가 달린 위키백과 문서, 1차 자료를 인용한 언론 기사 | 보충 근거, 해석 |
| **S3** 참고 | 누구나 편집하거나 출처가 약한 자료 | 나무위키, 개인 블로그, 커뮤니티, 출처 없는 기사·해설 | 개념 지도, 검색어 찾기. 단독 근거 불가 |
| **X** 사용 금지 | 검증할 수 없거나 쓰면 안 되는 자료 | AI가 생성한 요약·답변, 출처 불명 자료, 유료벽 우회본, 개인정보 포함 자료 | 등록하지 않음 |

같은 기관의 자료도 내용에 따라 등급이 다를 수 있습니다. 예를 들어 중앙은행의 **통계·결정문**은 S1이지만 **칼럼·교육용 해설**은 S2입니다.

## 등록 전 확인 (모든 출처)

1. **발행 주체**: 누가 썼고, 그 주제에 대해 권한이나 전문성이 있는가?
2. **원문 여부**: 요약·재인용이면 원문을 찾아 원문을 등록한다.
3. **시점**: 발행일·개정일을 확인한다. 금리·세율·법령은 현행인지 확인하고 기준 시점을 `note`에 적는다.
4. **관할**: 어느 나라의 규칙인가? 한국 규칙과 국제기준을 섞지 않는다.
5. **접근성**: 상대 CLI가 같은 URL로 다시 열 수 있는가? 로그인이 필요하면 쓰지 않는다.
6. **라이선스**: 재사용 조건을 `license`에 적는다(모르면 `확인 필요`).

## 교차 확인 (검토하는 CLI)

- 인용된 출처를 직접 열어 `locator` 위치에 그 내용이 실제로 있는지 확인한다.
- 수치는 단위·기준일·범위(연율인지, 명목인지)까지 맞는지 본다.
- 다른 S1 자료와 충돌하면 `dispute`로 두고 두 출처를 모두 적는다.
- URL이 열리지 않으면 `needs-source`로 판정한다. 기억에 의존해 확인하지 않는다.
