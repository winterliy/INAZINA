# 재무제표 추정 자동 채움 및 기업 구조 관리 개선

## 의도

관리자가 기업 재무제표를 업종 기반 추정으로 채우고, 기업 규모 분류·기업집단 대표·모회사 판단을 명확히 하며, 지분 경로에서 선택한 법인을 현재 조직도 안에서 찾을 수 있게 한다. 관련 API의 반복 DB 조회도 줄여 기업·조직도 화면의 대기 시간을 낮춘다.

## 목표

- 재무제표의 실제 거래 분개와 추정 분개를 구분하고, 추정 근거를 확인할 수 있게 한다.
- 새 설치 및 빈 설정에 제품 기본 규모 기준과 공시 기간을 제공한다.
- 기업집단 생성 때 대표기업을 구성원으로 등록하고, 기존 대표기업도 구성원 중 선택해 변경하게 한다.
- 법인자본에는 자기주식·국고 보유분을 제외한 단일 기업 주주 중 실제 의결권 지배력을 가진 회사만 모회사로 표시한다.
- 현재 지분 경로에서 법인을 선택하면 그래프를 다시 조회하지 않고 해당 노드를 가운데로 이동·강조한다.
- 기업 요약 및 소유 그래프 계산에서 반복되는 per-company/per-edge 쿼리를 배치 조회·요청 단위 캐시로 줄인다.

## 비목표와 안전장치

- 추정치는 실제 거래 또는 실제 공시 정보로 표현하지 않는다.
- 추정값으로 기존 분개를 덮어쓰거나 같은 달에 중복 생성하지 않는다.
- 기업별 법적·세무상 임계값으로 기본 규모 분류를 설명하지 않는다. 기본값은 게임 내 제품 기준이다.
- 여러 주주가 합산해 지배하는 경우, 한 곳의 모회사로 오인 표시하지 않는다. 모회사 표시는 한 회사가 의결권 과반을 보유하는 경우에만 한다.
- 최적화는 이 요청이 닿는 재무·법인 요약·소유 그래프 경로에 한정한다.

## 접근 방식

1. **원장에 추정 분개를 기록 (선택·권장):** 업종·규모와 실제 자료를 바탕으로 부족한 계정을 추정하고, 추정 표시가 있는 대차 일치 분개로 저장한다. 월·회사별 idempotency key로 재실행 중복을 막는다. 재무제표와 결산에 함께 반영된다.
2. **보고서에만 추정치 표시:** 저장·결산 영향은 없지만, 표시된 값과 원장·연결재무제표가 달라져 실제 자동 채움 요구에 덜 맞는다.

선택한 접근은 1번이다. 추정 분개는 실제 거래 분개를 덮지 않는다. 계정별로 해당 기간에 실제 분개가 있으면 그 계정은 추정 대상에서 제외한다. 추정값에는 `추정` 표시와 적용한 업종 계수·기초값을 남긴다. 재실행은 동일한 추정 분개를 중복 생성하지 않는다.

## 기본값

규모 분류 기본 설정은 `mode=any`, 공시 유예 604800초(7일)로 한다.

| 측정 기준 | 중소기업 상한 | 중견기업 상한 |
|---|---:|---:|
| 연매출 | 10,000,000,000 NWX | 100,000,000,000 NWX |
| 자산 | 10,000,000,000 NWX | 100,000,000,000 NWX |
| 종업원 | 300명 | 1,000명 |

빈 설정 데이터베이스는 이 기본값을 사용한다. 이미 관리자가 설정한 규칙은 마이그레이션에서 덮어쓰지 않는다. 관리 화면에도 빈 값 대신 활성 기본값을 표시하고 저장·초기화 동작을 구분한다.

## 동작 설계

### 업종 기반 재무제표 자동 채움

- 회사 원장의 기존 거래 대사와 월간 영업 인식은 유지한다.
- 관리자가 재무제표 수정 화면에서 `이번 달 추정 채우기`를 실행한다. 자동 현재 잔액 대사 후 이번 달에만 추정하며, 마감 월이나 과거 월은 받지 않는다. 과거 추정에는 당시 잔액 스냅샷이 없어 현재 상태를 과거에 잘못 반영할 수 있기 때문이다.
- 매출은 같은 회사의 최근 3개 완료 월 실제 매출 평균을 우선 사용한다. 이 자료가 없으면 `max(납입자본, 최근 실제 자산)`에 산업별 연간 매출/자본 회전계수를 곱해 12로 나눈다. 자본·자산이 모두 0이거나 자료가 없으면 매출을 만들지 않는다.
- 업종군은 산업명 키워드로 통신, 제조, 기술·소프트웨어, 금융, 유통, 일반으로 분류한다. 최근 12개월의 실제 매출·원가·판매관리비 이력이 있으면 각 비용/매출 비율을 우선 사용하고, 없으면 코드에 고정된 업종 기본비율을 사용한다. 첫 기본값은 제조(연매출 회전 1.5배, 원가 62%, 판관비 23%), 기술·소프트웨어(1.8배, 28%, 50%), 통신(0.35배, 38%, 40%), 금융(0.4배, 10%, 55%), 유통(2.4배, 70%, 22%), 일반(1.2배, 45%, 35%)이다. 합산 비용률이 100% 이상이 되면 이익이 생기도록 임의 조정하지 않고 해당 월 추정을 중단해 설정 오류를 표시한다.
- 감가상각은 실제 유형자산 장부 잔액이 있을 때 연 10%를 12개월로 나눈 값까지 추정하며, 자산 장부가를 초과할 수 없다. 종업원 수는 현재 원천 자료가 없으므로 추정하지 않는다. 기본 직원 수 경계는 직원 자료가 연결될 때까지 판정에서 비활성으로 남는다.
- 양의 추정 세전이익에만 게임 내 기본 세율 20%를 적용한다. 이는 세법값이 아닌 추정용 가정이며, 추정 분개 설명에 명시한다.
- 기존 월간 영업 프로필이 해당 월에 활성화되어 있으면 그 결과를 우선하고 별도 추정은 실행하지 않는다. 계정별로 해당 월에 실제 또는 프로필 분개가 이미 있으면 그 계정은 자동 채움에서 제외한다.
- 추정 분개는 외상 매출채권·매입채무를 사용해 현금을 바꾸지 않는다. 차대 균형, 결산 여부, 금액 한도를 검증하고 한 분개로 원자적으로 저장한다.
- 적용 계수·기초값은 분개 설명과 추정 메타데이터에 남기고 UI에 `추정` 배지를 붙인다.
- 결산된 기간에는 추정 실행을 막는다. 추정 취소는 원장 규칙에 맞춰 역분개한다.
- 계수는 코드의 명시적 산업군 설정으로 시작하고, 결과가 법정 수치나 실측치가 아님을 화면에서 밝힌다.

### 기업집단 대표기업

- 생성 폼의 대표기업 선택은 이미 선택한 법인을 기본값으로 제안한다.
- 대표기업이 선택되면 그 법인을 최초 구성원으로 추가한다.
- 집단 카드에서 현재 구성원 중 하나를 대표기업으로 바꾸거나 미지정으로 되돌릴 수 있다.
- API는 대표기업이 활성 구성원인지 검증한다.

### 모회사 판단

- 모든 발행 종류의 주당 의결권을 반영해 법인 주주별 직접 의결권을 합산한다.
- 국고 계정(거래소 매도 대기 재고 포함)과 발행 법인 자신의 계정이 보유한 주식은 의결권 분모와 주주 후보에서 제외한다.
- 한 법인이 직접 의결권 50% 초과를 가진 경우에만 그 법인 하나를 모회사로 반환한다. 과반 지배자가 없으면 모회사 표시를 하지 않는다.
- 요약 API에서 법인별 반복 조회를 피하도록 발행 권리·보유 수량을 한 번에 읽고 메모리에서 집계한다.

### 지분 지도 위치 찾기

- 현재 지분 경로 트리의 법인을 누르면 같은 그래프의 노드를 가운데 정렬하고 짧게 강조한다.
- 선택한 법인의 상세 그래프를 다시 요청하지 않는다. 전체 법인 검색에서 새 법인을 고른 경우에만 그래프를 로드한다.
- 같은 DOM 노드 ref와 최소 상태만 사용하고, resize 시 컨테이너 크기를 재사용한다.

### 성능

- 소유 그래프 계산 중 발행 종류·보유 수량을 요청 단위로 캐시하거나 배치 조회해 edge마다 반복하던 SQL을 없앤다.
- 법인 요약의 모든 회사 최대주주 계산을 단일 집계 쿼리/메모리 집계로 바꾼다.
- 조직 목록의 재무 지표를 회사마다 따로 계산하던 조회를 기간·회사 묶음 쿼리로 줄인다.
- 전 범위 코드 정리 대신 위 화면들의 실제 반복 조회와 계산을 우선 대상으로 한다.

## 제약 및 미결 설계 호출

- 재무 추정 계수는 제품용 출발값이다. 소스 데이터가 부족한 산업은 추정 대신 부족 자료를 표시한다.
- 개별 주주가 아닌 여러 회사의 연합으로만 과반이 되는 구조는 단일 모회사를 만들지 않는다.
- 보유 지도는 현재 그래프 안에서 포커스 이동만 하며, 회사 선택·URL의 그래프 기준은 바꾸지 않는다.

## 구현 후 확인

- 업종 기반 추정 분개가 대차 균형을 지키고, 재실행해도 중복되지 않으며, 실거래와 UI에서 구분되는지 확인한다.
- 저장된 기본값이 신규 설치·빈 설정에만 적용되고 기존 관리자 규칙을 유지하는지 확인한다.
- 그룹 대표가 구성원으로 검증되는지, 과반 지배자만 모회사로 표시되는지 확인한다.
- 지분 경로 선택이 API 재호출 없이 같은 노드를 화면 가운데로 이동시키는지 확인한다.
- 바뀐 API에서 반복 쿼리가 줄었는지 비교한다.
