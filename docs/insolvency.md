# 회생·파산 기준과 변경 방법

나루 '회생 · 파산' 탭으로 들어온 신청을 관리자 대시보드에서 **인가**하면 실제 처리가 바로 실행됩니다.
처리 코드는 `managers/insolvency_manager.py`, 인가 진입점은 `web_api/server.py`의 `admin_court_decide`입니다.

## 인가하면 일어나는 일

### 파산
1. 미체결 주문을 취소하고 이자를 정산합니다.
2. 주식·채권·통장을 처분해 현금으로 모읍니다.
3. **면제재산**만큼 현금을 남기고, 나머지를 본국 통화 대출에 잔액 비율대로 갚습니다(배당).
4. 남은 대출은 **면책**합니다. 은행 장부에는 상각으로 기록하고, 상각 채무 기록도 0으로 지웁니다.
5. 신용점수를 **파산 후 신용점수 상한** 이하로 내리고, **파산 후 대출 금지** 기간 동안 대출 신청·연장을 막습니다.
6. 계정 이용은 막지 않습니다.

### 회생
1. 자산은 그대로 둡니다.
2. 변제 총액은 다음 둘 중 큰 금액입니다. 대출 잔액이 상한입니다.
   - 대출 잔액 × **최소 변제율**
   - 청산가치: 총자산 − 면제재산. 파산했다면 채권자가 받았을 금액입니다.
3. 변제 총액을 **회생 기간**(주)으로 나눠 봇이 매주 자동으로 걷습니다. 기간은 인가할 때 대시보드에서 정할 수 있고, 비우면 국가 기본값을 씁니다. 최소~최대 범위를 벗어나면 범위 안으로 맞춥니다.
4. 변제 중에는 다음이 적용됩니다.
   - 이자, 연체 처리, 기존 정기상환이 멈춥니다.
   - 새 대출과 연장을 할 수 없습니다.
5. 다 갚으면 남은 대출을 면책하고, **회생 완료 후 대출 금지** 기간 동안 대출을 막습니다.
6. 잔액이 부족해 못 낸 횟수가 **허용 미납 횟수**를 넘으면 회생이 폐지됩니다. 빚이 원래대로 되살아나고, 그때부터 이자가 다시 붙습니다.
7. 매주 변제, 미납, 폐지, 완료를 Discord DM으로 알립니다.

### 공통
- 면책을 받으면 **재면책 금지** 기간 동안은 새 신청을 인가할 수 없습니다.
- 배당과 회생 변제는 **본국 통화 대출**에만 적용합니다. 외화 대출은 배당 없이 면책만 됩니다.

## 확정 기본값 (2026-11-14)

모든 국가에 같은 값이 적용됩니다. 대시보드에서 따로 저장한 국가만 다른 값을 씁니다.

| 항목 | 키 | 기본값 |
|---|---|---|
| 파산 면제재산 (본국 통화) | `exempt_amount` | 1,000,000 |
| 파산 후 신용점수 상한 (0~1000) | `bankruptcy_score` | 300 |
| 파산 후 대출 금지 (일) | `bankruptcy_ban_days` | 30 |
| 회생 인가 시 신용점수 상한 | `rehab_score` | 450 |
| 회생 기본 기간 (주) | `rehab_weeks` | 12 |
| 회생 최소 기간 (주) | `rehab_min_weeks` | 4 |
| 회생 최대 기간 (주) | `rehab_max_weeks` | 20 |
| 최소 변제율 (%) | `rehab_repay_percent` | 50 |
| 허용 미납 횟수 | `rehab_max_missed` | 1 (2회째 폐지) |
| 회생 완료 후 대출 금지 (일) | `rehab_ban_days_after` | 14 |
| 재면책 금지 (일) | `rediscard_days` | 90 |

신용점수는 "상한"입니다. 이미 이보다 낮은 사람은 점수가 그대로입니다.

## 변경 방법

### 국가 하나만 바꾸기 (대시보드)
1. 관리자 대시보드 → **회생·파산** 메뉴로 갑니다.
2. 아래쪽 **국가별 회생 · 파산 기준** 표에서 바꿀 칸에 새 값을 입력합니다. 칸에 흐리게 보이는 숫자가 현재 값이고, 비워 둔 칸은 바뀌지 않습니다.
3. 그 국가 열 맨 아래 **저장**을 누릅니다.
4. 저장한 국가는 열 머리의 "· 기본값" 표시가 사라집니다. 기록은 감사 로그에 `court.policy`로 남습니다.

API로 바꿀 때는 `POST /api/admin/court/policies/{국가명}`에 `{"values": {"exempt_amount": 500000}}`을 보내고, 조회는 `GET /api/admin/court/policies`로 합니다.

### 모든 국가의 기본값 바꾸기 (코드)
1. `managers/insolvency_manager.py` 위쪽의 `DEFAULTS`를 고칩니다.
2. 봇, Python 서버, Node API를 재시작합니다.
3. 이 값은 대시보드에서 따로 저장하지 않은 국가에만 적용됩니다.

### 저장 위치
- 국가별 값: `insolvency_policies` 테이블, 국가당 한 줄입니다. 값이 비어 있는 칸은 `DEFAULTS`를 씁니다.
- 사건 기록: `insolvency_cases`
- 대출 금지·최근 면책 시각: `insolvency_restrictions`

### 바꾼 값이 적용되는 시점
- 다음에 인가하는 신청부터 적용됩니다.
- 이미 진행 중인 회생의 주간 변제액과 기간은 인가할 때 정해져서 바뀌지 않습니다.
- 허용 미납 횟수와 회생 완료 후 대출 금지 기간은 매주 처리할 때 그때의 값을 읽습니다.
